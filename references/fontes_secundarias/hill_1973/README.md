# Hill (1973)

**Referência:** HILL, M. O. *Diversity and Evenness: A Unifying Notation and Its Consequences*. Ecology, 54, 427–432, 1973. [Fonte original](https://doi.org/10.2307/1934352).

**Papel no projeto:** Fundamenta os números efetivos de diversidade. O número de Hill de ordem 2 é aplicado às participações das saídas, sob a denominação número efetivo de destinos.
