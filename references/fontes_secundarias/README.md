- [`ghosh_1958/`](ghosh_1958/README.md): artigo fundador do modelo de alocação/oferta de Ghosh.
- [`vanessa_oliveira_moraes/`](vanessa_oliveira_moraes/README.md): dissertação sobre fluxos de água virtual e insumo-produto.
- [`ibge_scn_2010/`](ibge_scn_2010/README.md): relatório metodológico do Sistema de Contas Nacionais, referência 2010.
